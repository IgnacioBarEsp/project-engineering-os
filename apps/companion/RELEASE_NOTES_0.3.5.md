# Companion 0.3.5

Esta versión entrega las opciones de instalación de [#168](https://github.com/IgnacioBarEsp/project-engineering-os/issues/168): elección marcada de acceso directo, apertura opcional al finalizar y páginas en español. El instalador es para Windows x64, no tiene certificado de editor, sigue siendo por usuario, no pide elevación y conserva proyectos, historial y runtimes.

La publicación verifica en Windows la instalación, actualización desde 0.1.0 y desinstalación. El arnés aísla los datos de la app pero mantiene el perfil real del runner para comprobar el acceso directo del Escritorio.

Conserva el núcleo `create-project-engineering-os` 0.5.0 y no reemplaza los assets ni los tags anteriores.
