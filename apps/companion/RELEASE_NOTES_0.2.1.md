# Companion 0.2.1

Esta versión reúne mejoras compatibles integradas después de Companion 0.1.0:

- navegación clara entre Inicio, Tus proyectos, Preparar proyecto y Ayuda;
- estado comprobable por proyecto y guías adaptadas a investigación, software, Unity, contenido y trabajo general;
- contexto con límites explícitos, fuentes revisables y preparación que conserva archivos existentes;
- apertura de aplicaciones de escritorio según capacidades verificadas, sin convertir una elección de escritorio en una pestaña web;
- selección explícita de modelos cuando la persona decide usar un proveedor; mirar la pantalla no hace una llamada;
- herramientas administradas y CodeGraph opcional con límites de licencia, privacidad y verificación;
- mediciones y lenguaje que separan lo comprobado de lo que sigue pendiente.

El instalador es para Windows x64, se instala por usuario y no tiene certificado de editor. Windows puede
advertir al abrirlo; el manifiesto y `SHA256SUMS` permiten comprobar el archivo descargado, pero no
sustituyen una firma. No hay actualización automática, cuenta propia ni servicio de inferencia operado por
el proyecto.

Esta release conserva el núcleo `create-project-engineering-os` 0.5.0. No publica una nueva versión npm del
núcleo y no reemplaza los assets ni el tag de Companion 0.1.0. El tag de intento fallido `companion-v0.2.0`
permanece intacto y no tuvo una GitHub Release ni assets públicos.
