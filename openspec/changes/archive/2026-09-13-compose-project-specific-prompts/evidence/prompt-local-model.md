## Preparación antes de trabajar

Revisar los archivos .js y .md completos.

Verificar que los archivos .pdf estén disponibles para consulta.

Confirmar que el contexto pendiente se haya cargado.

## Cómo trabajar

Analizar el código en los archivos .js para entender el cálculo del presupuesto.

Leer el contenido de los archivos .md para obtener información contextual.

Consultar el archivo .pdf si es necesario.

Utilizar el agente codex para ayudar en la comprensión.

## Qué no está listo

El contexto pendiente aún no se ha procesado.

Un archivo .pdf no es legible.

## Reglas que no cambian

No modificar los archivos existentes.

No crear nuevos archivos.

No usar herramientas externas.

No suponer información adicional.
