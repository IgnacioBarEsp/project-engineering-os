# Proposal: Publicación de Companion 0.3.0 y Actualización Documental

Enlaza al issue #137.

## Motivación
El código fuente de la evolución integral de Companion (asistente de 4 pasos, 7 perfiles canónicos,
persistencia semántica de PROJECT_VISION.md, instalador contextual NSIS, microcopia humana y sistema de
diseño visual Impeccable) fue fusionado en main. Para completar el ciclo público, se requiere formalizar
la versión 0.3.0, actualizar la documentación oficial, publicar la galería de pantallas en docs/assets/companion/
y preparar el release ejecutable para Windows x64.

## Alcance
1. Incorporar galería de capturas oficiales en docs/assets/companion/ y docs/companion/SCREENSHOTS.md.
2. Actualizar README.md, docs/PROJECT_STATUS.md y docs/companion/INSTALLER.md.
3. Avanzar versión a 0.3.0 en package.json, package-lock.json, THIRD-PARTY-NOTICES.md y qa/packaging.mjs.
4. Redactar RELEASE_NOTES_0.3.0.md.
5. Preparar la publicación oficial para Windows x64 en GitHub Releases.
