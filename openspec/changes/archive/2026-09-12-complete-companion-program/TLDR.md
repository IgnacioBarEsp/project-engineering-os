# TLDR

**Use this if:** you want to know what the Companion application can be shown to do, and what it cannot.

Program #66 stayed open after #87, #80 and #81 because its native acceptance, its measurement against a
real model and its public delivery were never demonstrated. This change demonstrates them, publishes the
result including where it does not favour the product, and names what is still unproved.

## What it does

- Answers the interview that had been pending since 7 September: the conference is **24 September 2026**,
  the application has to be ready by the 20th, the AI that must work are OpenCode, Claude, ChatGPT, Cursor
  and Antigravity, and installation depth is settled — download only the hash-pinned toolchain, configure
  what already exists, and **never install a model or an inference engine**.
- Admits **Antigravity** as a selectable AI, detected and named, and **deliberately never launched**: its
  executable is unsigned and nothing here observed how its build takes a folder.
- Runs the five profiles through the **installed application's own window**, with the PDF and Word document
  those profiles promise, and resolves every citation against the file on disk.
- Runs a **paired inference experiment** against a real model. The result is a **tie**.
- Builds, verifies and **publishes** the Windows installer with its checksum, and deploys the landing.

## What the measurement says

Six trials, strict rubric, no normalisation: **15/15 grounded answers and 15/15 abstentions in both
conditions**. The prepared context used 30 times less context for identical quality, but that reduced input
tokens by only 15 % and it was **slower**. No saving in time or money is demonstrated, and the published
page says so in the row where the baseline ties.

## What it does not demonstrate

The installer's own wizard pages and the folder picker need a person — established by measurement, not
assumed. The native window does not exercise activation, the engineering apply or the code map; that is a
limit of the harness, recorded with its cause. The model experiment ran against a build older than the
delivered artifact. Nobody but the maintainer has installed the published release.

An independent adversarial review returned **FAIL** on the first pass, with two blockers and six majors.
Both blockers and five majors are resolved; `evidence/independent-review.md` keeps what was wrong.
