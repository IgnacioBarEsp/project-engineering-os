## Why

Issue #78 passed all 13 DoR checks after #77 merged in protected PR #83. Prepared folders need usable,
bounded source retrieval and task guidance before the desktop UI can honestly report context ready.

## What Changes

- Add offline text, PDF and DOCX extraction with provenance, visible coverage limits and freshness checks.
- Provide lexical retrieval, a compact navigation map and recipes for five profiles; no unmeasured savings.
- Add reviewed, recoverable entry points for selected agents and a preview-only web context export.
- Record exact graph-tool identities, licensing and activation limits; no automatic provider downloads.
- Keep document dependencies in the private Companion package, outside the universal npm core.

## Capabilities

### New Capabilities
- companion-context: attributed local retrieval, bounded recipes and checked agent entry points.

## Impact

Companion gains three pinned extraction dependencies and a separate Node 24 validation job. Core remains
dependency-free at runtime and supports its existing Node matrix. Source documents remain unchanged.
Approval is the maintainer's explicit delegation for #66 and its implementation issues; it does not
constitute a human usability study. Desktop, installer and actual comparative trials remain #79–#81.

Non-goals: embedding or LLM calls, automatic OCR/model downloads, executing repository code, blanket
graph-tool activation or claiming complete coverage of scanned PDFs, images, audio or videos.
Rollback restores only verified Companion changes and preserves user documents and intervening edits.
