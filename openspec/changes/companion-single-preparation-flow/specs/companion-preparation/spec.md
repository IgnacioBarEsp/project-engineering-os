## ADDED Requirements

### Requirement: Vision preview matches the owned output
Companion SHALL show a preview generated by the same pure renderer used for `PROJECT_VISION.md`. It SHALL distinguish the person's own answers from headings and questions supplied by the interface, and SHALL NOT insert suggested declarative answers into the saved vision.

#### Scenario: A person uses a vision prompt
- **WHEN** they click a suggested prompt
- **THEN** the editor SHALL insert only a heading and a question, not a factual claim about their project

#### Scenario: A person leaves the vision blank
- **WHEN** they continue without adding vision text
- **THEN** the preview and saved file SHALL retain the original stated objective, not an empty or generated intention

#### Scenario: A person reviews the file preview
- **WHEN** they inspect the Markdown before approving the plan
- **THEN** the preview SHALL match the file's renderer for the same selection and the plan SHALL be refreshed if those answers change
